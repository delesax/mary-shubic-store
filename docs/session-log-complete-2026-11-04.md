## Stripe PaymentElement replaces the card-only CardElement (2026-11-04, `cd1d208`, pushed, deployed 13:02 GMT)

- **Before (read from code, no env values read):** storefront `Payment` step mounted a `CardElement`; Review step's `PaymentButton` called `stripe.confirmCardPayment` then the `placeOrder()` server action. Backend: Medusa 2.15.5 Stripe provider `id: "stripe"` (webhook `/hooks/payment/stripe_stripe`), `capture: true`. PaymentIntent request: `capture_method: automatic`, no `payment_method_types`, no `automatic_payment_methods`.
