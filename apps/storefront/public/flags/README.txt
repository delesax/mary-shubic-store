Country flags (4x3 SVGs) copied from flag-icons 7.2.3 (https://github.com/lipis/flag-icons), MIT licence (see LICENSE).
They replace the jsDelivr CDN default of react-country-flag, so the storefront needs no third-party image host.

Included: gb de dk es fr it se us (the countries in the store regions on 2026-11-04).
To add a country (e.g. a new region): copy its file from flag-icons/flags/4x3/<code>.svg into public/flags/4x3/.
A country with no file here shows a broken image in the country picker.
